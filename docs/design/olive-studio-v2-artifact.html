Architecture

Panel hierarchy and proportions

One title bar, one activity bar, one primary sidebar, the editor group, one bottom panel, an optional secondary sidebar for OLIVE, one status bar. The editor always keeps priority: it never drops below 560 logical pixels wide.

Collapse order when space runs out
  • 1. The OLIVE rail hides first (below 1600 px wide). Every OLIVE space stays one click away through the title-bar space switcher and the command palette.
  • 2. Toolbar labels become icon-only buttons with tooltips and shortcuts (below 1440 px).
  • 3. The OLIVE secondary sidebar changes from docked to an overlay drawer when docking it would push the editor below 560 px.
  • 4. The primary sidebar becomes an overlay (below 1180 px). It reopens with its activity-bar icon or Ctrl+B.
  • 5. The panel is capped at 40% of the editor column height and can be maximised (Ctrl+J toggles it).

Keyboard first

Shortcuts

Bindings follow VS Code wherever Electron and Monaco allow it, so muscle memory transfers. Ctrl+Shift+I is left alone because it opens Electron developer tools.

Command palette

Commands and the functions they call

The palette lists only commands that map to a function Studio has today, or that are classed B/C here. Prefixes: none = files, > commands, # workspace symbols, @ symbols in the file, : go to line.

OLIVE Night · Studio theme

Syntax palette

Near-black navy editor, blue structure, warm strings, teal types. Green is kept out of syntax, so it still means OLIVE's own identity and success. Every token colour clears 4.5:1 against the editor background (measured values in OLIVE_STUDIO_V2.md).
