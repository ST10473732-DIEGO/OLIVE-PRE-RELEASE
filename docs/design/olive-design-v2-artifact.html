2 · Design System V2

Tokens

V2 keeps the "quiet instrument" values that already work, gives them semantic names, adds one panel layer and a computing accent, and fixes the one contrast failure (muted text on raised surfaces measured 3.71:1; V2 muted measures ≥ 4.69:1 on every surface). Every existing variable in tokens.css maps to a V2 name (see the handoff document §4).

Colour · semantic status

Colour rules
  • Blue is interaction: links, focus, selection, primary buttons (#2f74d0 fill with white text, 4.64:1). The light #7cc4ff stays for text-level accents and focus rings.
  • Cyan is computation: OLIVE actively thinking, streaming, running a job, or context that will be sent to a model. Never decoration, never a button fill.
  • Olive green is identity: the mark, the active-space indicator in navigation, the OLIVE author mark in Chat, and trusted/paired identity. Success green (#7fd8a8) is outcomes: verified, passed, online. The two tokens are separate and never swap.
  • Amber means your decision is needed (Ask, pending approval) or something recoverable. Red is terminal or blocking. Grey is off, offline or declined.
  • Status is never colour alone: every state carries an icon or a word (WCAG 1.4.1).

Typography

Spacing (4 px base)

Studio uses 2–8 internally; workspaces 8–24; page gutters 24–32. Dense rows: 22 (Studio tree), 30 (navigation), 34 (lists).

Radii

Desktop controls use 4–6. Menus, popovers and tooltips use 8. Dialogs and the Chat composer use 12. Full-round is reserved for status pills and avatars. The 16/20 "feature" radii are retired.

Borders and elevation

Structure comes from 1 px hairlines: border.subtle between regions, border.default around controls, border.strong on overlays.Shadows only on things that float above the page: menus, popovers, the palette, dialogs and toasts. Panels and list rows never have a shadow.Surface ladder, from back to front: base → panel → surface → elevated → raised.

3 · Components

Controls at desktop density

Default control height is 28 px, compact is 24 px, and 32 px is for the one primary action on a page. Heights drop from 34–36 px today. At 100% scale this is still above the WCAG 2.2 24 px target minimum.

6 · OLIVE Core

The Core shows activity. It is not a logo or a decoration.

Today's Core is a dot-matrix olive in the icon's green and pimento red. It rotates at Welcome and sits in the navigation brand slot. V2 keeps the renderer and the Welcome moment, and moves the compact Core into the title bar as a live activity indicator: olive dots at rest, cyan compute lighting only while OLIVE is really working, amber while it waits for you. The cyan state is new (class B: a renderer palette parameter). The app icon stays the solid green olive.
