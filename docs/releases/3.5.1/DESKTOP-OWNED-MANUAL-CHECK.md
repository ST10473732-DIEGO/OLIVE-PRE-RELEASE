# User-initiated owned-target acceptance

Prepared only. The previous attempt remains blocked in `M2_DESKTOP_ACCEPTANCE.md` and its original artifacts. This procedure has not yet demonstrated the target's UIA controls or the expected label. No automatic approval clicks are permitted.

1. Start `scripts/launch_desktop_acceptance.ps1` from a normal, non-administrator PowerShell. It creates a new temporary profile and opens the built Electron application, but does not launch the target or inspect any windows. It prints the isolated profile and target path. Never open Qt against this active profile.
2. Enter DMDO → Desktop Control → Control permissions → Desktop Control. Review the actual settings. Explicitly enable Desktop Control with UIA enabled; leave screen observation and vision fallback off. The narrowest currently supported text-entry setting is **keyboard policy Ask in this isolated profile**, with mouse policy **Deny**. Save only after you choose these settings. There is no new per-launch enablement override: an explicit Deny still blocks input. Inspection/control remain Ask and require their real action reviews. Do not create Allow rules or change the real profile.
3. Return to Desktop Control → Developer Details → **Launch and attach one target**. Choose **Python script**, then **Choose and review launch**. In the native file picker select exactly `scripts/m2_desktop_acceptance_window.py` from this repository. Do not select generated, imported or unrelated code. This is a direct trusted-code launch under existing `terminal.execute` and `system.open_application` reviews, not an execution sandbox. Untrusted code belongs in Studio's isolation path.
4. Review and personally confirm the real script-execution and application-launch approvals if their file, interpreter, hash-bound arguments and scope match this test. The assistant must not click these approval controls. Cancelling either approval must prevent launch. No permanent permission is created by a one-action confirmation.
5. Select the resulting backend-owned launch reference and click **Attach launched target**. This does not enumerate unrelated titles: it checks process IDs first, validates the owned launcher/child executable, exact script arguments and process lifetimes, then reads only owned windows. Personally confirm the actual scoped inspection request. No arbitrary HWND or manually seeded cache is used.
6. Verify the observed title is **DMDO M2 local acceptance target**, with the intended entry and **Check text** control actually exposed by UIA. Process/window lifetime is recorded in the real observation. If no usable controls appear, report exactly what was observed and stop. Source-code widget declarations do not count as accessible-control evidence. Do not switch applications or use coordinates.
7. Select the observed entry, choose `set_text`, enter exactly **DMDO local acceptance**, then **Review and perform action**. Personally confirm the exact keyboard/control approval(s). DMDO must verify the window lifetime and foreground before input; its own approval UI may hand focus back to the verified target. Any other focus change/user takeover is a stop condition.
8. Select the actual **Check text** control, choose `invoke`, and set expected visible control to **Verified: DMDO local acceptance**. Review and personally confirm the real action approval. Verify that exact label in the resulting observation. Do not edit the target's internals.
9. Use **Stop Control** (native fallback Ctrl+Alt+Escape where registered). Record the actual backend state. A stopped latch is distinct from evidence that an in-flight operation was interrupted. Capture only this target/result and relevant DMDO state; no unrelated windows.
10. Close only the newly launched test target and isolated Electron instance. Retain the temporary profile/logs as evidence if needed. Do not terminate another Python process by name. If automated cleanup is needed, use the verified launch record, process creation identity and owned window; the previous launcher-PID-only assertion must not be reused.
